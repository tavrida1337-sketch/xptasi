# xptasi

Увеличивает размер обоймы. Есть 2 режима: X — умножает боезапас (если изначально 100 ПТ, то на x2 станет 200, и так далее), и кастом — установка своего количества патронов, например, для золотого АК-47 (чекбокс «x» в меню). Также в меню option можно выбрать свой бинд или команду. Написан на C++.

GTA SA 1.0 US + SAMP 0.3.7.

## Сборка

Нужны CMake и Visual Studio с C++ workload. Запустить `build.bat` (x86 Release).
Готовый `xpt.asi` кладётся в корень игры (путь выхода задан в `CMakeLists.txt`).

## Использование

- Открытие меню: команда чата (по умолчанию `/xpt`, меняется во вкладке `option`) или бинд (по умолчанию `Insert`).
- Вкладки `ak47` / `uzi` / `obrez`: `enable`, чекбокс `x` (множитель 1–30) или свое число патронов, клик по `pt:` — ввод с клавиатуры.
- Настройки хранятся в реестре `HKCU\Software\xpt`, чекбокс `cfg` — автосейв.
