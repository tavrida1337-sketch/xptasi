Увеличивает размер обоймы. Есть 2 режима: X — умножает боезапас (если изначально 100 ПТ, то на x2 станет 200, и так далее), и кастом — установка своего количества патронов, например, для золотого АК-47 (чекбокс «x» в меню). Также в меню option можно выбрать свой бинд или команду. Написан на C++. Работает только на 3 оружиях: золотые АК, УЗИ и обрезы.
